Usage: scotch apply COMMAND

Sends the registries under .github/ to the repository on GitHub.

╭─ Commands ───────────────────────────────────────────────────────────────────╮
│ labels    Creates or updates every label .github/labels.toml declares on the │
│           repository the checkout's remote names, then prints each live      │
│           label the registry omits, which stays on GitHub until it is        │
│           renamed or deleted by hand.                                        │
│ rulesets  Updates in place each live ruleset sharing the name of a file      │
│           under .github/rulesets/, creating the ruleset where none does,     │
│           then sends every setting .github/settings.toml declares beside the │
│           description pyproject.toml declares, the domain of its homepage,   │
│           and its keywords as the repository's topics, and prints each live  │
│           ruleset no file names, which stays on GitHub until it is deleted   │
│           by hand.                                                           │
╰──────────────────────────────────────────────────────────────────────────────╯
