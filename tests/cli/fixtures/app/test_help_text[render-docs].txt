Usage: scotch render docs

Writes each file a declaration in the repository renders into, meaning the JSON 
the site's theme reads, the favicon and each lockup, the part of a page a       
declaration fills in, the figures a page sets inside its sentences, and the     
footnote definitions closing each Markdown file, printing the path of each file 
it changed.                                                                     

Writes the files the index renders into as well where one has been built under  
the data directory, which is .cache/data under the project's root unless the    
[tool.scotch] table of its pyproject.toml or the SCOTCH_DATA variable moves it, 
and otherwise prints that it left them as they stand.                           

Exits nonzero naming the index where the one built there holds another layout,  
and otherwise naming the file it was writing, where a page's markers enclose    
other than one region, where a page cites a key no entry of docs/references.bib 
holds, where that file holds a block or an entry that cannot be read, or where  
an example line the pages draw holds no game read with no error or shares no    
position with a stored game.
