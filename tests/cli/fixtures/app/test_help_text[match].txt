Usage: scotch match COMMAND

Matches a submitted game against the stored games.

╭─ Commands ───────────────────────────────────────────────────────────────────╮
│ game   Finds the stored game sharing the longest unbroken run of positions   │
│        with one game of a PGN file.                                          │
│ games  Matches every game of a PGN file against the index of stored games.   │
╰──────────────────────────────────────────────────────────────────────────────╯
