Usage: scotch cite COMMAND

Prints the footnote definition citing a source.

╭─ Commands ───────────────────────────────────────────────────────────────────╮
│ source  Prints the footnote definition citing each source named by its key   │
│         in docs/references.bib, in the order given, each on one line with a  │
│         blank line between two of them, ready to paste beneath the text of   │
│         an issue or a pull request citing it, since a page takes its own     │
│         from scotch render docs.                                             │
╰──────────────────────────────────────────────────────────────────────────────╯
