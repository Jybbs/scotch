Usage: scotch apply rulesets

Updates in place each live ruleset sharing the name of a file under             
.github/rulesets/, creating the ruleset where none does, then sends every       
setting .github/settings.toml declares beside the description, the homepage, and
the topics pyproject.toml declares, and prints each live ruleset no file names, 
which stays on GitHub until it is deleted by hand.                              

Exits nonzero before writing anything where a ruleset, the settings, or the     
manifest fails to read, and at the first call gh fails to send.
