Usage: scotch audit repo [OPTIONS]

Reports every divergence the checks in scotch.repo find in the repository at the
project's root, printing one line per finding that names its file relative to   
that root, and exits with status 1 where any finding is an error rather than a  
warning.

╭─ Parameters ─────────────────────────────────────────────────────────────────╮
│ --output-format CHOICE  Whether each finding prints as a line of text or as  │
│                         the workflow command GitHub Actions turns into an    │
│                         annotation. [choices: github, text] [default: text]  │
╰──────────────────────────────────────────────────────────────────────────────╯
