Usage: scotch COMMAND

Finds the grandmaster game sharing the longest run of positions with a submitted
chess game and shows how that game continued.

╭─ Commands ───────────────────────────────────────────────────────────────────╮
│ match        Matches a submitted game against the stored games.              │
│ --help (-h)  Display this message and exit.                                  │
│ --version    Display application version.                                    │
╰──────────────────────────────────────────────────────────────────────────────╯
