# Reference

What does each command take, each setting change, and each word mean? This section holds the lookups a reader reaches for while running *Scotch*, each written from the declaration it describes rather than kept beside it, so a change to the code reaches its page through the next `mise run docs:render`.

Each page of this section answers one question:

| **Page** | **Question It Answers** |
|---|---|
| [The Commands](commands.md) | *What does each command take, print, and stop on?* |
| [Settings](settings.md) | *Which settings does a command read, and where does it read each one from?* |
| [The Match File](match.md) | *What does the match file hold, and how does an address carry it?* |
| [Terms](terms.md) | *What does each word these pages use mean?* |

The address `scotch match game --link` prints shows how the pages fit together. [The Match File](match.md) sets out the object the address carries in its fragment, [The Commands](commands.md) the options of the command that printed it, [Settings](settings.md) the `SCOTCH_DATA` directory the command read the index from, and [Terms](terms.md) the run and the parting move the match reports, both of which the drawing below marks on the example match the [Viewer](../viewer/index.md) opens on.
