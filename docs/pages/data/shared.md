# Shared Positions

A match runs only as far as the stored game it finds stays in positions the submitted game also reaches, so how long the stored games share their positions with one another bounds how far a match runs on the store. Each count below comes from the index by `mise run docs:render`, a stored game playing another's whole mainline from its start counting as a copy of it, as [Matches the Rule Passes Over](../methods/limits.md) counts one, and a copy never counting as a second game sharing a position.
