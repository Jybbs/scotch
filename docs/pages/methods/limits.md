# Matches the Rule Passes Over

The longest run is one reading of closeness among several, and the measures below count how often it passes over a match a reader would also want. Each comes from <!-- sample -->1,000<!-- /sample --> stored games drawn at random, each matched as though submitted against every other stored game save those holding its whole mainline, and `mise run docs:render` counts them anew from the index.

## Ties on the Longest Run

Of the sampled games, <!-- tied -->47%<!-- /tied --> share their longest run with more than one stored game, and the match names only the first of them, as [The Longest Run](runs.md) sets out.

## Runs Through Crowded Positions

In <!-- crowded -->8%<!-- /crowded --> of the sampled games, the longest run lies wholly in positions more than <!-- crowd -->100<!-- /crowd --> other stored games reach, so the match shows a well-trodden line rather than a game that reached a position few others did.

## Rarer Positions by Another Order

In <!-- transposed -->57%<!-- /transposed --> of the sampled games, a shorter run with some stored game reaches, by another order of moves, a position rarer than every position of the longest run, which the rule passes over because it counts positions rather than weighing how rare each one is.
