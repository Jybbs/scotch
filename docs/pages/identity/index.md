# Identity

Which colors, faces, and marks is the site drawn in, and where does each come from? *Scotch* is drawn in the chess set and the tournament hall, meaning the board, its pieces, and the score sheet, and every color, face, and mark a page shows comes from one declaration in the package, which `mise run docs:render` writes into the values each page reads.

Each page of this section answers one question about the identity:

| [Marks](marks.md) | *How is the mark drawn, and how does each size of it read?* |

The positions both games share sit on the board's `light` and `primary` squares, the submitted game's squares lift away in the color of the `submitted` role and the stored game's in the color of the `stored` role, the two roles every page draws the games in, and the key above them is set in the `code` face that sets every move and figure.
